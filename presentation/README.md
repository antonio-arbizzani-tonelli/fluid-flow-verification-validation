# Presentation

The 36-slide deck presents the project as a standalone research portfolio: numerical verification and validation of pipe-flow simulations, followed by calibration and experimental analysis of a circular-cylinder wake. Two supplementary slides document the low-Reynolds-number resolution limits and the spatial consistency of the PSV shedding estimate.

- [`fluid_flow_verification_validation.pdf`](fluid_flow_verification_validation.pdf) is the fixed-layout reading copy.
- [`fluid_flow_verification_validation.pptx`](fluid_flow_verification_validation.pptx) is the editable source deck.

The supporting figures and numerical results are described in the root README and in the LaTeX report source under `docs/report/`.
